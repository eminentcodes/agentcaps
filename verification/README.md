# Verification artifacts

`page-review.json` records the UI and API review results. Screenshots are generated by `npm run test:browser` and remain local. `product-capture.json` records the capture used for the landing page's real product image. Server logs are ignored.

Contract and authorization tests run with `npm test`. Build and type checks run separately. UI checks do not execute funded wallet transactions, and local blockchain verification is not a Base Sepolia deployment.

`faucet-audit.json`, when generated, records live faucet availability and account or verification requirements. A faucet page being available does not establish that a wallet received funds; confirm that through `npm run status:testnet`.
