Entrants need a working MVP people can use and a live URL. Submissions can be edited until the build window closes. Entry is open to everyone; token holdings are not required to compete.

The published announcement says "Building on Base? Base's docs are the place to start." It does not explicitly state that every MVP must deploy on Base. The holder vote uses balances on Base, and possible future raises can launch on Base or Robinhood Chain; those statements are separate from the MVP deployment requirement. Unavailable application fields have not been checked for additional conditions.

| Criterion | Weight | AgentCaps delivery evidence |
| --- | --- | --- |
| Execution | 30% | Full funding, payment, rejection, revocation, and withdrawal flow; contract and browser checks. |
| Launch potential | 25% | Clear use case for teams delegating paid work to crypto agents; future paid reporting and management. |
| Originality | 20% | Separate, enforceable allocations for individual agent jobs. |
| Craft and UX | 15% | Clear controls, truthful transaction states, readable receipts, and accessible interactions. |
| Vibecoding leverage | 10% | Build record explaining AI-assisted implementation and verification. |

The community holders' scorecard counts as another judge. The cash pool is $1,000 across the top five. A Fundable result link is optional and does not change the rubric.

AgentCaps remains a testnet-only build targeting Base Sepolia, as requested and reaffirmed by the user on November 8. Arc was discussed as a funding alternative, but no migration was made and no public contract has been deployed. No application or submission has been sent from this workspace.
